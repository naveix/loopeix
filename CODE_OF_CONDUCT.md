# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: participation here is expected to be harassment-free for everyone, regardless of who
they are. Be respectful in issues, pull requests, and reviews; critique code and evidence, not
people. Trolling, insults, harassment, or publishing others' private information are not
acceptable.

## Enforcement

Report conduct issues privately to the maintainer via
[GitHub private vulnerability reporting](https://github.com/naveix/loopeix/security/advisories/new)
(marked "conduct", not a technical advisory) or through the contact listed on the maintainer's
GitHub profile. Reports are reviewed and acted on at the maintainer's discretion, up to and
including permanent bans from the project. The full text of the Covenant, including the
enforcement-guidelines ladder, applies.
